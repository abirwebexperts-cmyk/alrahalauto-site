# Image Upload Guide — Al Rahal Auto Maintenance

Upload every file to **public_html/assets/img/** using the exact folder and file name below.
Until a file is uploaded the site shows a neutral dark placeholder with the file name, so nothing breaks.
Format: JPG (quality 80) or WebP renamed to .jpg is fine. Keep each file under 400 KB.
